# Города России: концентрация населения и сегментация

Анализ 1117 городов России на реальных данных Rosstat: где сосредоточено городское население, чем различаются федеральные округа и на какие естественные группы делятся города.

## Ключевые выводы
- На Москву и Санкт-Петербург приходится 17,5% всего городского населения набора, на топ-10 городов — 27,5%.
- Медианный город — 26 тыс. жителей, средний — 92 тыс.: сильный правый перекос, распределение близко к логнормальному.
- Городское население смещено на запад: лидируют Центральный (≈30,8 млн) и Приволжский (≈19,7 млн) округа.
- Города образуют 4 сегмента (размер + география): крупные западные центры · малые города севера и центра · восточные (Сибирь и Дальний Восток) · южные.

## Методы
Очистка данных · агрегации (`groupby`) · анализ распределения (log-преобразование) · кластеризация KMeans с выбором k по методу локтя · геовизуализация.

## Стек
Python · pandas · scikit-learn · matplotlib

## Как запустить
1. `pip install pandas scikit-learn matplotlib`
2. Открыть `russian_cities.ipynb` (Jupyter / Google Colab)
3. Положить рядом `towns.csv` и выполнить ячейки по порядку

## Данные
- Датасет: [epogrebnyak/ru-cities](https://github.com/epogrebnyak/ru-cities) — файл `assets/towns.csv` (население, координаты, регион, федеральный округ)
- Первоисточник: Rosstat, «Регионы России. Основные социально-экономические показатели городов»
- Данные реальные; все расчёты и выводы — собственные.
